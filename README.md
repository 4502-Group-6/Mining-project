# Project title
Predicting Hotel Booking Cancellations

# Team members
- Seiji Aoyama
- Elaine French

# Description of the project
- This project aims to develop a predictive model to accurately forecast whether a hotel booking will be canceled. By analyzing historical reservation data and applying machine learning techniques, we seek to identify key factors—such as lead time, deposit type, pricing, and booking channels—that influence cancellation behavior. Our approach involves data preprocessing, exploratory data analysis (EDA), model development and refinement, and interpretation of feature importance to support actionable insights for hotel managers.

# Summary of the question(s) sought and the answers
### Primary Questions:
Can we accurately predict which hotel bookings are likely to be canceled?
Which attributes most strongly influence the likelihood of cancellation?

### Answers:
Using classification models (e.g., Decision Trees), we achieved around 83.8% accuracy in predicting cancellations. Key factors influencing cancellations include deposit requirements, average daily rate (ADR), lead time, and certain booking channels.

# Application of this knowledge
By understanding why and when cancellations occur, hotel managers can:
- Revenue Management: Adjust rates and deposit policies based on predicted cancellation risks, leading to more stable occupancy and improved profit margins.
- Customer Engagement: Offer targeted incentives or flexible options to high-risk bookings, encouraging guests to maintain their reservations.
- Operational Efficiency: Better forecast staffing and resource needs by anticipating no-shows, ensuring smoother day-to-day operations and enhanced guest experiences.
